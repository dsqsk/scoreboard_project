# 规则讨论记录

## 已确认

- 产品面向本人和朋友小范围使用。
- 支持微信分享与房间码加入房间，加入者都是参赛者，均可记分。
- 房间可以连续开多场比赛，每场单独保留记录，开赛前选择玩法，可在不同场次切换台球与扑克。
- 杀球使用15张对应号码球的扑克牌，两张Joker分别对应14和15号。三人通常各分5张；四人通常按4、4、4、3分配。
- 杀球中率先打完自己名下全部球者获胜，其余人记录剩余球数为负几球。
- 杀球不记录逐颗球及过程惩罚，只录入最终结果。赢家正分等于其他玩家剩余球数之和，其他玩家分别记负的剩余球数，合计为0。
- 杀球打进对手球时，该球捞回台面并转归击球者；自己球与白球同时落袋时，自己球无效。两种情况同杆发生时分别生效。
- 打分模式的球无个人归属，扑克牌用于记录对应号码球的得分。所有人从公共牌区选择自己打进的号码，累计对应分数。
- 打分模式不处理击球顺序和其他惩罚；用户描述为全部打完后结算。
- 打分结算：总分120，个人基准分为120÷参赛人数，个人输赢分为进球累计分减去基准分。例如三人获得60、40、20分，输赢为+20、0、−20；四人基准分为30。120不是每人的初始账户分。
- 九球采用中式九球，仅支持两人或三人，累计分数。用户给定默认分值序列1、4、7、10；检索对应为犯规1、普胜4、小金7、大金10，待确认三人结算对象。
- 每场开始固定参赛名单，中途加入者从下一场参赛。
- 打分公共牌只能归一人，先成功提交生效；所有成员可退回或改归属，显示修改人。
- 保留每场与累计成绩，各玩法分别统计，九球累计分数。

## 三人九球规则依据

用户指定采用：https://www.zqsjsoft.cn/rules/zhuifen.html 。优先于此前检索的两人赛事规则。

- 普通犯规：自己−1，上家+1，下家自由球。此前暂拟的下家得分已作废。
- 普胜：自己+4，上家−4；小金：自己+7，上家−7。
- 大金：自己+20，其余两人各−10。
- 让杆：下家要求上家继续击打；让杆者犯规时自己−1、下家+1，下家自由球。合法解球未进不计分，交下家继续。让杆清台向下家收双倍：普胜8、小金14、网页另列大金20；第三人不变。
- 页面还包含黄金九（开球者+8、其余各−4）、开球黑金（开球者−8、其余各+4）及普通黑金。普通黑金有其他球时按普通犯规；仅剩9号时上家+1、下家+4、自己−5。
- 用户确认首版不包含黄金九、黑金、让杆大金。
- 用户确认不维护击球顺序，只统计分数；每个人直接操作自己的正负分，不选择输赢对象、不自动联动他人分数。
- 用户接受快捷加减分按钮；三人大金赢家一次记+20，输家各自记−10。具体交互形式留到UI/UX阶段讨论。
- 九球持续记分，不要求逐局创建、逐局结束或点击结束本场；分数随操作保存并反映到累计成绩，重新进入可继续。此前“结束后才计入累计”的建议不适用于九球。
- 九球各参赛者分数合计不为0时提示差额，不通过强制结束或结算步骤处理。
- 两人九球的具体加减分口径尚待明确。
