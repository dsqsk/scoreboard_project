# 打大A线上对局规则

状态：规则草案，依据用户提供的9张游戏规则截图整理。仅适用于截图对应的五人版本，不代表其他地区或平台的统一规则。

范围：真人五人联机打牌，包括发牌、亮A、出牌、取蛋和结算。本文不是现有线下记分器的需求变更；现有记分器规则保留于 `da-a-rules.md`。本文未明确的规则不得直接沿用旧计分表或其他扑克游戏规则。

## 1. 基本设置与阵营

- 5位玩家，使用两副完整扑克牌，共108张。
- 发牌过程中抢亮的一张A及另一副牌中同花色的A，成为本局的两张大A。
- 两张大A分别由两人持有：主方2人、抓方3人。
- 两张大A由一人持有：主方1人、抓方4人，即独打。
- 无大A的玩家属于抓方。阵营是本局属性，不能理解为固定座位或固定搭档。
- 截图提及不洗牌模式，但未说明是否默认开启及其具体收牌、切牌规则。

## 2. 亮A与反A

- 大A花色由发牌过程中的抢亮确定；截图没有规定默认花色。
- 一名玩家亮大A后，其他玩家若持有花色相同的两个A，可以反大A，反后视为该玩家明亮双A。
- “花色相同”指所持两张A相互同花色；反后如何更新大A花色、是否允许再次反、反A时限尚待确认。
- 大A属于特殊牌，其他花色的A为普通A。
- 除规则要求亮出的信息外，玩家只能看到自己的手牌；搭档身份何时公开尚待确认。

## 3. 单牌大小

```text
大A > 大王 > 小王 > 3 > 2 > 普通A > K > Q > J > 10 > 9 > 8 > 7 > 6 > 5 > 4
```

- 单张大A可以管任何其他单牌，包括大王。
- 单张大A只能作为单张管较小的单牌，不能直接压对子等牌型。
- 单王也只能作为单张管较小的单牌。
- 花色是否参与普通同点数牌的比较，截图未说明。

## 4. 牌型定义

| 牌型 | 定义 | 示例 |
| --- | --- | --- |
| 单张 | 任意一张牌 | `5` |
| 对子 | 两张点数相同的牌 | `22` |
| 龙 | 三张或以上点数连续的牌 | `567` |
| 双龙 | 三对或以上点数连续的牌 | `55 66 77` |
| 蛋子 | 三张点数相同的牌 | `222` |
| 大蛋子 | 四至六张点数相同的牌 | `55555` |
| 双王 | 任意两张王 | 大王、小王的组合；不限一大一小 |
| 连珠蛋 | 三个连续的蛋子 | `777 888 999` |
| 假八 | 两个连续的四张大蛋子 | `7777 8888` |
| 真七 | 七张或八张点数相同的牌 | 七张9或八张9 |
| 三王 | 任意三张王 | 两张大王加一张小王等 |
| 四王 | 全部四张王 | 两张大王、两张小王 |
| 双大A | 两张本局大A | 最高牌型 |

“连续”的边界不能从单牌大小顺序直接推导。A、2、3能否参与龙、双龙、连珠蛋或假八，均需确认。

## 5. 压牌关系

截图给出的高阶牌型顺序为：

```text
双大A > 四王 > 三王 > 真七 > 假八 > 连珠蛋 > 双王 > 大蛋子 > 双龙
```

截图还给出：蛋子可以管龙、对子和一般单张，并明确以下例外。

- 蛋子与双龙互相不能管。
- 大蛋子可以管双龙。
- 压单王至少需要蛋子；较大的单张也按单牌规则处理。
- 压单张大A，需要截图所述“5张以上的大蛋子”门槛。“以上”按原文保留，是否包含五张及更高牌型如何适用，待确认。

这些关系不能压缩成一条无条件的全序。例如，不能因为蛋子能管一般单张，就允许三张普通牌管单张大A；也不能让双龙与蛋子相互压制。

同类牌型的比较规则尚不完整：是否必须同长度、张数是否优先、同点数是否区分花色、不同王组合是否区分大小，截图均未明确。图中蛋子、龙、对子、单张的排列也不能直接理解为任意跨类型均可压制。

## 6. 4取蛋

4是最小单牌，同时具有取蛋能力：使用规定数量的4，可以把别人打出的蛋子或大蛋子取到自己手中。

| 使用的4 | 截图明确的取牌目标 |
| --- | --- |
| 两张4 | 三张蛋子 |
| 三张4 | 四张大蛋子 |
| 四张4 | 五张大蛋子 |

- 截图说明“以此类推”，但未明确可取的最大张数、能否取真七及其他特殊组合，不能自行扩展为全部牌型。
- 取蛋改变手牌归属，不等同于普通压牌或直接弃掉目标牌。
- 使用的4如何处理、取蛋是否占用当前回合、操作窗口和后续出牌权，均待确认。

## 7. 完整规则冻结前必须确认

| 编号 | 待确认事项 |
| --- | --- |
| R01 | 108张牌如何分配；发牌起点、顺序，以及各座位牌数。 |
| R02 | 无人亮A如何处理；亮A与反A时限、优先级、可反次数、反后花色。 |
| R03 | 谁先出牌、出牌方向、有人出完后的接风或领出规则。 |
| R04 | 过牌后同一轮能否再次接牌；多少人过牌后清桌并重新领出。 |
| R05 | 各连续牌型的点数范围；连珠蛋是否严格三组、假八是否严格两组。 |
| R06 | 龙、双龙等跟牌是否等长；蛋子、大蛋子、真七的同类比较规则。 |
| R07 | 单张大A的五张门槛是否包含五张；高阶牌型压单王、大A的完整规则。 |
| R08 | 取蛋是否必须恰好对应张数；是否可取队友的蛋；4的去向与取牌后出牌权。 |
| R09 | 明暗A、搭档身份的公开时机；显示剩余牌数等公开信息的范围。 |
| R10 | 对局何时结束，是否必须确定五人全部名次，以及阵营胜负和平局条件。 |
| R11 | 搭档与独打的计分表、明A与反A倍数、底分、交枪等房间选项。 |
| R12 | 超时、断线、离房、托管和解散时如何处理当前对局。 |
